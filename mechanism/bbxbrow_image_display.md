The mode comparison explains the asymmetry. In “all images,” the unresolved graphic already reserves its declared geometry, so streamed pixels can be invalidated in place. Intelligent mode first lays out a compact placeholder; the first streamed frame changes that placeholder to real geometry, marks the cell/table dirty, and requires reflow. Later frames normally need redraw only. The safe design therefore needs one geometry restart at a layout-event boundary—not a restart request that lets one stale cell run first.
